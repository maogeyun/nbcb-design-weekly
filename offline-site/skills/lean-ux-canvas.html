Lean UX Canvas

将精益创业与 UX 结合：一张画布对齐业务问题、假设、目标用户、MVP 与成功指标，驱动快速验证。

Lean UX 画布适合 新功能孵化、大改版前的对齐，把设计和工程拉到同一套“假设—实验—指标”语言上。

画布建议区块（可随团队模板微调）

1) 业务问题：若不解决，业务上最坏会怎样？

2) 用户假设：谁是用户？情境？当前替代行为？

3) 核心假设（Belief）：我们相信什么若为假则方案无意义？（尽量可证伪）

4) MVP / 实验：最小交付物是什么？Wizard of Oz、原型、分流量均可

5) 成功指标：行为指标优先；事先写清及格线

6) 时间盒：何时复盘决定继续/转向？

工作坊节奏（90–120 分钟）

  • 个人静默填 → 贴墙对齐 → 争论假设而非 UI → 定 owner 与下周实验

与假设验证板

  • 画布偏 倡议级一页对齐
  • 假设验证板偏 多假设表格追踪；可把一个倡议拆成多行假设
