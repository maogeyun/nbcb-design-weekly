NOW-NEXT-LATER 是路线图的“诚实革命”：不用季度日期制造承诺，而是用优先级与信心度表达真实不确定性，让对话从“为什么延期”转向“什么最有价值”。

## 三个桶（递减细节与信心）

- **NOW（高信心）**：正在做（任务级别，可拆子任务）
- **NEXT（中等信心）**：接下来做（功能级别，方向明确但细节可变）
- **LATER（低信心）**：以后可能做（只写结果/问题，不写解决方案）

关键：**越往后越用结果描述**，例如“降低新用户流失率”，而不是“做积分系统”。

## 适用场景

- 替代季度时间轴路线图
- 对客户/销售沟通方向（传达信心而非日期）
- 管理层汇报优先级（把讨论聚焦到价值与选择）
- 早期产品方向快速变化时
- 季度规划更新（NEXT→NOW，LATER 重新评估）

## 维护规则（避免退化成 backlog）

- NOW 不能超过团队真实并行能力
- LATER 禁止加日期
- LATER 不是积压清单：每季度清理、合并、删除
- 明确声明：这是沟通工具，不是交付承诺
- 至少季度更新一次（过期比没有更糟）
