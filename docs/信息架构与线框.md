## 1. 站点地图

```
宁波银行设计周刊
├── /                     首页 — 最新一期入口（最新周刊等同于首页呈现）
├── /weekly/current       重定向至首页（最新周刊导航目标）
├── /weekly/:issueId      周刊详情（核心阅读页，历史期或从“查看全部”进入）
├── /article/:id          文章落地页
├── /archive              周刊归档
├── /about                关于与版权说明
└── /admin/*              编辑后台（需鉴权）
```

**当前版本不包含**：登录、注册、收藏、我的、搜索（P1）。

## 3. 页面线框

│ Hero                                    │

```
┌─────────────────────────────────────────┐
│ ← 首页    第 1 期                       │

│ 本期导语（可选）                         │

│ [ 全部 ] [ UI设计 ] [ 设计经验 ] [ AI前沿 ]│
├─────────────────────────────────────────┤
│ ┌─ UI设计 ─────────────────────────────┐ │
│ │ [UI] 文章标题                        │ │
│ │ 引言摘要前 100 字…                   │ │

├─────────────────────────────────────────┤
│ [ 分享本期链接 ]  [ 查看归档 ]           │
└─────────────────────────────────────────┘
```

### 3.3 文章落地页 `/article/:id`

```
┌─────────────────────────────────────────┐
│ 首页 > 第 1 期 > 文章标题               │
├─────────────────────────────────────────┤
│ [AI前沿]                                │
│ 文章标题（原文）                         │
│ Figma Blog · 2026-06-10 · 英文          │
├─────────────────────────────────────────┤
│ 引言正文（150-300 字完整展示）           │
├─────────────────────────────────────────┤
│        [ 阅读原文 → ]  （主 CTA）        │
│ [ 返回第 1 期 ]  [ 复制链接 ]            │
├─────────────────────────────────────────┤
│ 本文由 AI 辅助摘要，请访问原文获取完整内容  │
└─────────────────────────────────────────┘
```

**外链失效态**：CTA 置灰 + 原文 URL 可复制。

│ 周刊归档                                 │

## 4. 组件清单

| 组件 | 用途 | 页面 |
|------|------|------|
| `GlobalNav` | 顶栏导航 | 全站前台 |
| `MobileTabBar` | 底部 Tab | 移动端 |
| `WeeklyHeroCard` | 首页最新期卡片 | `/` |
| `CategoryTabs` | 栏目筛选 Tab | `/weekly/:id` |
| `WeeklyArticleCard` | 周刊文章卡片 | 周刊页 |
| `ArticleIntro` | 完整引言区 | 落地页 |
| `ReadOriginalButton` | 阅读原文 CTA | 卡片/落地页 |
| `ArchiveListItem` | 归档列表项 | `/archive` |
| `EmptyState` | 空状态 | 多页 |
| `PageFooter` | 页脚 | 全站 |
