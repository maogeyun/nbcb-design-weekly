## 1. 版权与收录原则

### 1.1 基本原则

- **仅收录公开可访问** 的设计类文章，通过 RSS、官方 API 或合规抓取获取元数据
- **站内仅展示**：标题、来源、发布时间、150–300 字 AI 辅助引言、原文外链
- **禁止**：全文转载、正文图片本地化、绕过付费墙抓取
- **引言定位**：二次创作摘要，引导用户访问原文，不可替代原文阅读

### 1.2 版权声明模板（用于 `/about` 页）

> 宁波银行设计周刊所收录文章均来自互联网公开发布渠道。本站仅提供编辑策展与 AI 辅助摘要，不拥有原文著作权。如需阅读完整内容，请通过「阅读原文」访问原作者页面。若您是版权方且认为收录不当，请联系 [UED 团队邮箱] 处理。

### 1.3 抓取合规检查清单

| 检查项 | 要求 |
|--------|------|
| robots.txt | 允许抓取列表页/RSS，或仅使用官方 RSS |
| 服务条款 | 无明确禁止聚合摘要+链接 |
| 付费内容 | 不收录需登录/付费的全文 |
| 去重 | 同一 `original_url` 全站唯一，跨期不重复 |
| 失效链接 | 发布前人工确认；定期巡检 `link_status` |

## 5. 抓取技术规则

### 5.1 抓取频率

| 类型 | 频率 |
|------|------|
| RSS 源 | 每 6 小时轮询 |
| 人工监控源 | 编辑每周一、三手动补链 |
| 微信公众号 | WeWe RSS 后台定时更新 + 抓取轮询 |
| 元数据字段 | title, url, published_at, source_name, og:image（可选） |

### 5.2 候选池入库条件

- 发布时间在 **近 14 天** 内
- 来源在白名单内
- URL 未存在于历史已发布文章
- 标题/摘要含设计相关信号（非专用源需规则过滤）
- 跨源 URL 去重（同一链接只保留最早命中的来源）

### 5.3 拒绝收录情形

- 纯产品广告、招聘帖、课程推销
- 政治敏感、非设计主题
- 无法生成合规引言（抓取失败且无人工摘要）
- 原文需付费或登录墙
